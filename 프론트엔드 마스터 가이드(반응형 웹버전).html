🚀 웹 개발 기초 가이드 (HTML + CSS + JS)

🏗️ 1. HTML: 웹페이지의 뼈대

① 제목 & 문단 (h1~h6, p)

글자가 작을수록 더 큰 제목을 의미하며(h1이 가장 큼), 일반적인 줄글이나 문단은 <p> 태그를 사용합니다.

💻 예시 코드
<h1>제일 큰 제목</h1>
<h2>두 번째 제목</h2>
<p>이것은 일반적인 문단입니다.</p>
🖥️ 화면 결과

제일 큰 제목

두 번째 제목

이것은 일반적인 문단입니다.

② 링크 & 이미지 (a, img)

<a>는 클릭하면 이동하는 링크, <img>는 이미지를 보여줍니다. alt는 이미지가 안 보일 때 대신 띄워줄 글자입니다.

💻 예시 코드
<a href="https://google.com">구글로 이동</a>
<br>
<img src="https://via.placeholder.com/100" 
     alt="샘플 이미지">
🖥️ 화면 결과
구글로 이동

③ 목록 & 표 (ul/li, table)

순서가 없는 기본 목록은 <ul>과 <li>를 씁니다. 표는 <table> 안에 가로줄 <tr>, 칸 <td>를 넣습니다.

💻 예시 코드
<ul>
  <li>사과</li>
  <li>바나나</li>
</ul>

<table border="1">
  <tr>
    <td>1번 칸</td><td>2번 칸</td>
  </tr>
</table>

  • 바나나

④ 버튼 & 입력창 (button, input)

사용자가 아이디를 치거나 클릭할 때 쓰는 상호작용 태그입니다.

💻 예시 코드
<input type="text" placeholder="이름 입력">
<button>제출하기</button>
🖥️ 화면 결과

⑤ 시맨틱 태그 (header, main, footer)

의미 없는 <div> 대신 역할에 맞는 태그를 쓰면 코드 읽기가 훨씬 쉬워집니다.

💻 예시 코드
<header>머리글 (로고, 메뉴)</header>
<main>핵심 본문 내용</main>
<footer>바닥글 (저작권)</footer>

🎨 2. CSS: 웹페이지의 디자인

① 기본 색상 변경 (color, background)

원하는 태그를 선택해 글자색과 배경색을 지정합니다.

💻 예시 코드
p {
  color: blue;
  background-color: yellow;
}
🖥️ 화면 결과

파란색 글씨, 노란색 배경

② 화려한 리스트 만들기

HTML의 기본 <ul> 태그에 CSS 그라데이션과 그림자 효과를 입히면 훨씬 다채롭게 변합니다.

💻 예시 코드
.fancy-list li {
  background: linear-gradient(135deg, #f6d365, #fda085);
  box-shadow: 0 4px 6px rgba(0,0,0,0.1);
}
🖥️ 화면 결과

  • 바나나 (디자인 적용)

③ 애니메이션 버튼 (Hover & Transition)

:hover를 쓰면 마우스를 올렸을 때 동작을 지정할 수 있고, transition으로 변화를 부드럽게 만듭니다.

💻 예시 코드
.hover-btn {
  background-color: #9b59b6;
  transition: all 0.3s ease;
}
.hover-btn:hover {
  background-color: #8e44ad;
  transform: translateY(-5px) scale(1.05);
}
🖥️ 화면 결과

④ 마법의 배치 기술 (Flexbox)

display: flex;를 부모에게 주면, 안에 있는 박스들이 알아서 예쁘게 옆으로 나열됩니다. 레이아웃의 핵심 기술입니다.

💻 예시 코드
.flex-container {
  display: flex;
  gap: 15px; /* 박스 사이 간격 */
}
.flex-box {
  flex: 1; /* 똑같은 비율로 공간 차지 */
}

⚙️ 3. JavaScript: 웹페이지의 동작

① 클릭 이벤트 (기본 알림창)

버튼을 클릭했을 때 알림창(alert)을 띄우는 가장 기본적인 자바스크립트입니다.

💻 예시 코드
let btn = document.querySelector('#alertBtn');
btn.addEventListener('click', function() {
  alert('버튼을 눌렀네요!');
});
🖥️ 화면 결과

② 실시간 숫자 카운터

변수에 숫자를 저장하고, 클릭할 때마다 화면의 숫자를 더하거나 빼서 즉시 바꿔줍니다.

💻 예시 코드
let count = 0;
document.querySelector('#plus').addEventListener('click', function() {
  count = count + 1;
  document.querySelector('#number').textContent = count;
});
🖥️ 화면 결과

0

③ 다크모드 스위치 (Class Toggle)

classList.toggle()을 사용하면 HTML 태그에 특정 디자인(클래스)을 껐다 켰다 할 수 있습니다.

💻 예시 코드
const box = document.querySelector('#themeBox');
const toggleBtn = document.querySelector('#toggleBtn');

toggleBtn.addEventListener('click', function() {
  box.classList.toggle('dark'); 
});
