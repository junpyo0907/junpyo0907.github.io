파이썬 핵심 커리큘럼 및 실전 가이드

각 개념의 상세한 작동 원리 설명과 원클릭 복사가 가능한 파이썬 예시 코드

Part 1. 숫자형 (Number)

1. 숫자형 자료란?
파이썬에서 정수, 실수, 복소수 등 사칙연산과 수치 계산을 처리하는 기본 데이터 타입입니다. 데이터 분석 및 수학적 연산의 기초가 되며, 파이썬 내부적으로 자동 메모리 관리가 이루어집니다. 
# 숫자형 자료 변수 선언 및 연산 예시
integer_val = 100
float_val = 3.14
print("합계:", integer_val + float_val)  # 정수와 실수의 연산 결과는 실수(float)로 변환됩니다.
2. 정수형 (Integer, int)
양의 정수, 음의 정수, 0을 나타냅니다. 파이썬의 int 타입은 오버플로우 제한이 없어서 메모리가 허용하는 한 매우 큰 숫자도 안전하게 다룰 수 있습니다. 
positive = 42
negative = -100
zero = 0
big_int = 123456789012345678901234567890  # 매우 큰 숫자도 문제없이 처리 가능

print(type(big_int))  #
3. 실수형 (Floating-Point, float)
소수점이 포함된 실수 자료형입니다. 천문학적 숫자나 매우 작은 소수를 표현할 때는 소문자나 대문자 e를 사용한 과학적 표기법(e 표기법)을 지원합니다. 
pi = 3.141592
num_e = 2.5e4     # 2.5 * 10^4 = 25000.0
small_e = 1.5e-3  # 1.5 * 10^-3 = 0.0015

print(num_e, small_e)
4. 복소수형 (Complex, complex)
실수부와 허수부로 이루어진 복소수를 표현하며, 수학식(i)과 달리 파이썬에서는 허수부를 기호 j 또는 J로 표기합니다. 
comp = 3 + 4j

print("실수부:", comp.real)  # 3.0
print("허수부:", comp.imag)  # 4.0
print("켤레복소수:", comp.conjugate())  # (3-4j)
5. 숫자형 간의 연산
기본 사칙연산 외에도 나눗셈 후 정수 몫만 구하는 몫 연산자(//), 나머지를 구하는 나머지 연산자(%), 거듭제곱(**)을 지원합니다. 
a, b = 10, 3

print("나눗셈(/):", a / b)   # 3.3333333333333335 (float 반환)
print("몫(//):", a // b)     # 3 (정수 몫만 반환)
print("나머지(%):", a % b)   # 1 (홀짝 판별이나 주기 계산에 유용)
print("거듭제곱(**):", 2 ** 10) # 1024 (2의 10승)
6. 형 변환 (Type Conversion)
숫자 형태의 문자열이나 다른 숫자형 간에 타입을 명시적으로 변환할 때 내장 함수 int(), float() 등을 사용합니다. 
str_num = "2026"
converted_int = int(str_num)  # 문자열 "2026" -> 정수 2026으로 변환
float_num = float(converted_int) # 정수 -> 실수 2026.0으로 변환

print(converted_int + 10)  # 2036
print(float_num)           # 2026.0
7. 유용한 내장 함수
수치 계산을 돕는 파이썬 기본 제공 함수들로, 절댓값, 반올림, 거듭제곱, 최대·최소값을 쉽게 계산할 수 있습니다. 
print(abs(-15))          # 15 (절댓값)
print(round(3.14159, 2)) # 3.14 (소수점 둘째 자리까지 반올림)
print(pow(2, 4))         # 16 (2 ** 4와 동일)
print(max(10, 50, 20))   # 50 (가장 큰 수)
print(min(10, 50, 20))   # 10 (가장 작은 수)

Part 2. 문자열 (String)

1. 문자열 자료란?
글자, 단어, 문장 등 텍스트를 처리하기 위한 데이터 타입입니다. 파이썬의 문자열은 한 번 생성되면 내부 글자를 직접 변경할 수 없는 불변(Immutable) 시퀀스입니다. 
greeting = "Hello, Python!"
# greeting[0] = "h"  # 주석 해제 시 TypeError 발생 (불변성)
print(greeting)
2. 문자열 만들기
작은따옴표나 큰따옴표, 여러 줄 문장을 작성하는 따옴표 3개(""")로 작성하며, 이스케이프 문자(\n 줄바꿈, \t 탭)로 특수 출력을 제어합니다. 
single = 'Hello'
double = "Python"
multi_line = """첫 번째 줄
두 번째 줄(줄바꿈 유지)"""
escaped = "이름:\t홍길동\n나이:\t25"

print(escaped)
3. 문자열 인덱싱과 슬라이싱
인덱싱은 0부터 시작하는 특정 위치의 문자 한 개를 가져오며, 슬라이싱 [start:stop:step]은 특정 구간의 부분 문자열을 추출합니다. 
text = "Python Programming"
print(text[0])       # P (첫 번째 문자)
print(text[-1])      # g (뒤에서 첫 번째 문자)
print(text[0:6])     # Python (인덱스 0부터 5까지 추출)
print(text[::-1])    # gnimmargorP nohtyP (문자열 역순 정렬)
4. 문자열 포매팅
문자열 내부에 동적으로 변수 값을 삽입하는 방법으로, 최근에는 가독성과 성능이 가장 뛰어난 f-string 방식(f"...")이 표준처럼 쓰입니다. 
name = "지수"
score = 95

# 1. f-string 방식 (가장 권장됨)
print(f"학생 {name}의 점수는 {score}점입니다.")

# 2. .format() 메서드 방식
print("학생 {}의 점수는 {}점입니다.".format(name, score))

# 3. % 연산자 방식 (구버전)
print("학생 %s의 점수는 %d점입니다." % (name, score))
5. 주요 문자열 메서드
문자열을 변형하거나 찾고, 가공하는 파이썬 내장 메서드입니다. 공백 제거, 단어 치환, 분리 및 결합 기능을 자주 사용합니다. 
s = "  Python,Java,C++  "
print(s.strip())             # 양쪽 공백 제거 -> "Python,Java,C++"
print(s.replace("Java", "JS")) # 문자열 치환 -> "  Python,JS,C++  "

languages = s.strip().split(",")  # 구분자(,)를 기준으로 나누어 리스트 반환
print(languages)                  # ['Python', 'Java', 'C++']
print(" / ".join(languages))      # 리스트 요소를 하나의 문자열로 결합 -> "Python / Java / C++"
6. 문자열 연산
문자열에 + 연산자를 쓰면 앞뒤를 이어 붙이고, * 연산자를 사용하면 지정한 횟수만큼 문자열을 반복 출력합니다. 
line = "=" * 30
title = " " * 5 + "로그인 프로그램" + " " * 5

print(line)
print(title)
print(line)
# ==============================
#      로그인 프로그램     
# ==============================

Part 3. 불 자료형 (Boolean)

1. 불(Boolean) 자료형이란?
참(True) 또는 거짓(False) 오직 두 가지 값만 가질 수 있는 자료형입니다. 프로그램의 분기점(조건문, 반복문)을 제어할 때 사용됩니다. 
is_login = True
is_admin = False

print(type(is_login))  #
2. 참(True)과 거짓(False) 선언
파이썬에서 불리언 값을 선언할 때는 반드시 첫 글자를 대문자(True, False)로 기재해야 하며, 소문자 사용 시 변수로 인식하여 에러가 발생합니다. 
correct_flag = True   # 정상 선언
# wrong_flag = true   # NameError: name 'true' is not defined
3. 비교 연산자와 불 자료형
두 값을 비교하는 연산자(==, !=, >, <, >=, <=)의 실행 결과는 언제나 불 자료형(True/False)을 반환합니다. 
print(10 == 10)   # True (같음)
print(5 != 10)    # True (같지 않음)
print(15 < 10)    # False
4. 논리 연산자
여러 개의 불 조건을 연결하거나 뒤집을 때 and(모두 참), or(하나라도 참), not(논리 반전) 키워드를 사용합니다. 
age = 25
has_license = True

# age가 20 이상이고 운전면허가 있으면 True
can_drive = (age >= 20) and has_license
print("운전 가능 여부:", can_drive)  # True

print("논리 반전:", not True)       # False
5. 참과 거짓으로 평가되는 값들 (Truthy & Falsy)
일반 데이터 타입도 조건문에서 참이나 거짓처럼 평가됩니다. 비어있는 값이나 0은 거짓(False)으로 판별되며, 요소가 존재하면 참(True)으로 판별됩니다.
구분 Falsy (거짓으로 판정) Truthy (참으로 판정)
숫자형 0, 0.0 0이 아닌 모든 수 (-1, 1, 100 등)
시퀀스/컬렉션 "" (빈 문자열), [], (), {} 내부에 요소가 1개라도 있는 모든 자료 구조
기타 None, False True 및 인스턴스 객체 
# 리스트가 비어있으면 False, 데이터가 있으면 True로 처리됩니다.
items = []

if not items:
    print("리스트가 비어 있습니다.")  # 출력됨

Part 4. 리스트 (List)

1. 리스트 자료형이란?
여러 개의 다양한 데이터(숫자, 문자열, 심지어 다른 리스트)를 순서대로 나열하여 묶어 놓은 가변(Mutable) 자료형으로, 데이터의 추가·수정·삭제가 자유롭습니다. 
mixed_list = [10, "Python", 3.14, [1, 2, 3]]
print(mixed_list)
2. 리스트 생성과 인덱싱/슬라이싱
대괄호 []로 생성하며, 문자열과 마찬가지로 인덱스를 통해 원소에 접근하거나 슬라이싱을 통해 하위 리스트를 잘라낼 수 있습니다. 
fruits = ["apple", "banana", "cherry", "mango"]

print(fruits[1])      # banana (0번부터 시작하므로 두 번째 요소)
print(fruits[1:3])    # ['banana', 'cherry'] (1번부터 2번 인덱스까지 슬라이싱)
3. 리스트 값 수정 및 삭제
특정 위치의 인덱스에 새 값을 대입하여 원소를 덮어쓰거나, del 문, pop()(위치 기반 삭제), remove()(값 기반 삭제)를 사용할 수 있습니다. 
data = ["a", "b", "c", "d"]
data[0] = "Z"       # 인덱스 0번 요소 수정 -> ['Z', 'b', 'c', 'd']

del data[1]         # 1번 인덱스 요소('b') 삭제
last_item = data.pop()  # 맨 뒤 요소('d')를 꺼내고 리스트에서 삭제
data.remove("c")    # 값이 "c"인 원소를 찾아 삭제

print("최종 리스트:", data)      # ['Z']
print("pop으로 꺼낸 값:", last_item) # d
4. 주요 리스트 메서드
원소를 추가하는 append(), 특정 위치에 넣는 insert(), 리스트를 정렬하는 sort()와 역순으로 배치하는 reverse()가 자주 쓰입니다. 
numbers = [4, 2, 1, 3]
numbers.append(5)         # 맨 뒤에 5 추가 -> [4, 2, 1, 3, 5]
numbers.sort()            # 오름차순 정렬 -> [1, 2, 3, 4, 5]
numbers.reverse()         # 리스트 순서 뒤집기 -> [5, 4, 3, 2, 1]

print(numbers)
5. 리스트 연산
두 개 이상의 리스트를 + 연산자로 병합할 수 있으며, * 연산자를 사용하여 원소들을 지정한 수만큼 반복 확장합니다. 
list1 = [1, 2]
list2 = [3, 4]

print(list1 + list2)  # [1, 2, 3, 4]
print(list1 * 3)      # [1, 2, 1, 2, 1, 2]
6. 리스트 컴프리헨션 (List Comprehension)
반복문과 조건문을 한 줄의 대괄호 속에 압축하여 새로운 리스트를 직관적이고 빠르게 생성하는 파이썬 특유의 고급 구문입니다. 
# 1부터 10까지 숫자 중 짝수만 찾아서 그 제곱 값을 원소로 갖는 리스트 생성
even_squares = [x**2 for x in range(1, 11) if x % 2 == 0]

print(even_squares)  # [4, 16, 36, 64, 100]

Part 5. 튜플 (Tuple)

1. 튜플 자료형이란?
리스트와 거의 비슷하지만, 한 번 선언하고 나면 내부 요소를 수정·추가·삭제할 수 없는 불변(Immutable) 시퀀스 자료구조입니다. 
colors = ("red", "green", "blue")
# colors[0] = "yellow"  # 주석 해제 시 TypeError: 'tuple' object does not support item assignment
2. 튜플과 리스트의 차이점
튜플은 요소 변경을 허용하지 않는 대신 리스트보다 메모리를 적게 차지하며 처리 속도가 빠릅니다. 위경도 좌표, 시스템 설정값처럼 값이 바뀌지 말아야 할 때 적합합니다. 
# 불변이어야 안전한 위치 좌표 (위도, 경도) 예시
seoul_coords = (37.5665, 126.9780)
print("서울 위도:", seoul_coords[0])
3. 튜플 생성과 인덱싱/슬라이싱
소괄호 ()를 사용해 생성합니다. 단, 요소가 1개뿐인 튜플을 만들 때는 수학식 소괄호와 구분하기 위해 반드시 끝에 쉼표(,)를 붙여야 합니다. 
single_tuple = (10,)  # 쉼표가 없으면 일반 정수형 int로 인식함
numbers = (0, 10, 20, 30, 40)

print(type(single_tuple))  # 
print(numbers[1:4])        # (10, 20, 30) (슬라이싱 지원)
4. 튜플 패킹(Packing)과 언패킹(Unpacking)
여러 변수를 소괄호 없이 나열해 하나의 튜플로 묶는 것을 패킹, 묶인 튜플을 여러 개별 변수에 한 번에 나누어 할당하는 것을 언패킹이라고 합니다. 
# 튜플 패킹
user_info = "홍길동", 30, "서울"

# 튜플 언패킹 (각 변수에 순서대로 대입됨)
name, age, city = user_info
print(f"{name}님은 {city}에 거주하며 {age}세입니다.")

# * 연산자를 이용한 가변 언패킹
first, *others = (10, 20, 30, 40)
print(first)   # 10
print(others)  # [20, 30, 40] (나머지는 리스트로 묶임)
5. 튜플 관련 주요 메서드 및 내장 함수
수정 메서드는 없으나, 특정 값의 개수를 세는 count()와 특정 원소의 위치를 찾는 index(), 전체 길이 확인을 위한 len()을 활용할 수 있습니다. 
tpl = (1, 2, 2, 3, 2, 4)

print("2의 개수:", tpl.count(2))  # 3
print("3의 위치:", tpl.index(3))  # 3 (인덱스 번호)
print("전체 길이:", len(tpl))     # 6

Part 6. 딕셔너리 (Dictionary)

1. 딕셔너리 자료형이란?
인덱스 번호 대신 의미 있는 키(Key)와 그에 매핑되는 값(Value)을 한 쌍으로 저장하는 해시(Hash) 구조의 자료형으로, 대용량 데이터에서도 조회 속도가 매우 빠릅니다. 
book_prices = {"python": 25000, "java": 30000}
print(book_prices)
2. 딕셔너리 생성 및 요소 추가/삭제
중괄호 {}로 생성하며, dict[새로운_키] = 값 형태로 요소를 추가하거나 수정하고 del dict[키] 문으로 삭제합니다. 
user = {"id": 'user123', "name": "김철수"}
user["age"] = 28          # 새로운 키-값 쌍 추가
user["name"] = "김영희"   # 기존 키의 값 변경

del user["id"]            # 'id' 키-값 쌍 삭제
print(user)               # {'name': '김영희', 'age': 28}
3. Key를 이용해 Value 얻기
dict[key]는 존재하지 않는 키를 찾을 때 에러(KeyError)를 내지만, dict.get(key, default)를 쓰면 에러 없이 안전하게 기본값을 받을 수 있습니다. 
profile = {"name": "앨리스", "role": "admin"}

# print(profile["email"]) # KeyError 발생
print(profile.get("email")) # None 반환 (프로그램 안 멈춤)
print(profile.get("email", "이메일 정보 없음")) # 기본값을 지정해 반환
4. 주요 딕셔너리 메서드
키들의 모음을 얻는 keys(), 값들의 모음을 얻는 values(), 키-값 쌍을 튜플로 묶어서 반환하는 items(), 병합하는 update()가 있습니다. 
info = {"a": 10, "b": 20}

print(list(info.keys()))    # ['a', 'b'] (리스트로 변환하여 사용)
print(list(info.values()))  # [10, 20]
print(list(info.items()))   # [('a', 10), ('b', 20)]

info.update({"c": 30, "a": 100}) # 다른 딕셔너리를 병합 및 업데이트
print(info)                      # {'a': 100, 'b': 20, 'c': 30}
5. 딕셔너리 사용 시 주의사항
하나의 딕셔너리 안에서 키(Key)는 절대 중복될 수 없으며, 키로 사용할 데이터 타입은 값이 변하지 않는 불변(Immutable) 타입(문자열, 숫자, 튜플)이어야만 합니다. 
valid_dict = {(1, 2): "좌표 키는 가능"}  # 튜플은 불변이므로 Key로 사용 가능
# invalid_dict = {[1, 2]: "에러 발생"}  # 리스트는 가변이므로 Key로 쓰면 TypeError 발생

Part 7. 집합 (Set)

1. 집합 자료형이란?
수학의 집합 개념을 구현한 자료형입니다. 중복된 원소를 허용하지 않고, 요소들 간의 순서(인덱스)가 없다는 핵심적인 특징이 있습니다. 
# 리스트의 중복 데이터를 손쉽게 제거하는 용도로 자주 활용됩니다.
raw_list = [1, 2, 2, 3, 3, 3, 4]
unique_set = set(raw_list)

print(unique_set)  # {1, 2, 3, 4} (중복 제거됨)
2. 집합 생성하기
중괄호 {}나 내장 함수 set()으로 만듭니다. 주의할 점은 빈 중괄호 {}는 빈 딕셔너리로 인식되므로 빈 집합은 반드시 set()으로 만들어야 합니다. 
empty_dict = {}     # 빈 딕셔너리
empty_set = set()   # 빈 집합

print(type(empty_dict), type(empty_set))
3. 집합 연산
수학적 집합 연산인 합집합(|), 교집합(&), 차집합(-), 대칭차집합(^, 공통 원소 제외)을 기호 연산자로 손쉽게 수행합니다. 
s1 = {1, 2, 3, 4}
s2 = {3, 4, 5, 6}

print("합집합(|):", s1 | s2)    # {1, 2, 3, 4, 5, 6}
print("교집합(&):", s1 & s2)    # {3, 4}
print("차집합(-):", s1 - s2)    # {1, 2}
print("대칭차집합(^):", s1 ^ s2) # {1, 2, 5, 6}
4. 주요 집합 메서드
하나의 요소 추가는 add(), 다중 추가는 update()를 사용합니다. 삭제 시 remove()는 없으면 에러를 뱉지만, discard()는 에러를 무시합니다. 
my_set = {10, 20}
my_set.add(30)           # 단일 추가 -> {10, 20, 30}
my_set.update([40, 50])  # 여러 개 추가 -> {10, 20, 30, 40, 50}

my_set.discard(999)      # 존재하지 않는 값 999를 지워도 에러 없음
# my_set.remove(999)     # 주석 해제 시 KeyError: 999 발생
print(my_set)

Part 8. 파이썬 조건문 (Conditional Statements)

1. 조건문이란?
특정 조건식의 참·거짓(True/False) 여부에 따라 실행할 코드를 다르게 분기하여 프로그램의 흐름을 지능적으로 제어하는 문법입니다. 
temperature = 30
if temperature > 25:
    print("날씨가 덥습니다. 에어컨을 켭니다.")
2. if, elif, else 기본 구조
조건식 뒤에는 반드시 콜론(:)을 붙여야 하며, 위에서 아래 순서대로 검사하다가 참인 블록을 실행하고 빠져나갑니다. 
score = 83

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"   # 83 >= 80 이므로 이 블록이 실행됨
else:
    grade = "C"

print("성적 등급:", grade)  # B
3. 조건문에 사용되는 비교/논리 연산자
비교 연산자와 and, or, 그리고 시퀀스 내 존재 여부를 확인하는 멤버십 연산자 in, not in을 함께 조합해 사용합니다. 
ban_list = ["admin", "root", "system"]
user_id = "guest"

# user_id가 금지 목록에 없고, 글자 수가 3글자 이상인 조건
if (user_id not in ban_list) and (len(user_id) >= 3):
    print("사용 가능한 아이디입니다.")
4. 들여쓰기(Indentation) 규칙
파이썬은 중괄호 {} 대신 들여쓰기(공백 4칸 권장)로 코드 블록의 포함 관계를 인식합니다. 들여쓰기를 실수하면 IndentationError가 발생합니다. 
is_ready = True
if is_ready:
    print("준비 완료.")       # 정확히 공백 4칸 들여쓰기
    print("출발합니다!")      # 같은 블록 내 명령은 들여쓰기가 같아야 함
#   print("에러")             # 들여쓰기 수가 다르면 에러 발생
5. 한 줄 조건문 (삼항 연산자)
간단한 조건 분기 결과를 한 줄로 변수에 할당할 때 사용하는 구문으로, 참일_때_값 if 조건식 else 거짓일_때_값 형태를 띱니다. 
age = 18
# 나이가 20 이상이면 "성인", 아니면 "미성년자" 대입
status = "성인" if age >= 20 else "미성년자"

print("현재 상태:", status)  # 미성년자

Part 9. 파이썬 반복문 (Loops)

1. 반복문이란?
동일하거나 유사한 처리를 하는 코드를 일일이 적지 않고, 특정 범위나 조건이 만족할 때까지 자동으로 반복 실행하도록 해주는 제어 구조입니다. 
for i in range(3):
    print(f"반복문이 {i+1}번째 실행 중입니다.")
2. while 문
지정된 조건식이 참(True)인 동안 계속해서 반복합니다. 종료 조건이 충족되지 않으면 무한 루프에 빠지므로 조건 변화 로직이 필수입니다. 
count = 5
while count > 0:
    print(f"카운트다운: {count}")
    count -= 1  # 1씩 감소시켜 0이 되면 루프 자동 종료
print("발사!")
3. for 문과 range() 함수
리스트나 문자열 같은 시퀀스를 순차 순회하거나, 정수 연속 번호 생성을 돕는 range(시작, 끝, 증감폭) 함수와 결합하여 정해진 횟수만큼 반복합니다. 
# range(1, 10, 2)는 1부터 10 미만까지 2씩 증가 -> 1, 3, 5, 7, 9
for num in range(1, 10, 2):
    print(num, end=" ")  # 1 3 5 7 9
print()
4. break와 continue
break는 반복문을 완전히 강제 탈출할 때 사용하고, continue는 이번 반복의 남은 아래 코드를 스킵하고 다음 회차로 진행할 때 씁니다. 
for i in range(1, 10):
    if i == 3:
        continue  # 3은 출력하지 않고 건너뜀
    if i == 6:
        break     # 6이 되는 순간 반복문을 완전히 중단함
    print(i, end=" ")
# 출력 결과: 1 2 4 5
5. 반복문과 함께 쓰는 유용한 함수
순회 중에 인덱스 번호와 원소를 동시에 꺼내는 enumerate()와, 여러 시퀀스의 동일한 인덱스끼리 묶어 순회하는 zip() 함수입니다. 
names = ["철수", "영희", "민수"]
scores = [85, 95, 100]

# 1. enumerate()로 인덱스와 이름 동시 추출
for idx, name in enumerate(names, start=1):
    print(f"{idx}번 학생: {name}")

# 2. zip()으로 이름 리스트와 점수 리스트를 병렬 순회
for name, score in zip(names, scores):
    print(f"{name}의 시험 점수는 {score}점입니다.")

Part 10. 파이썬 내장 함수 (Built-in Functions)

1. 내장 함수란?
별도의 모듈을 설치하거나 import로 불러오지 않아도 파이썬이 기본으로 제공하는 활용도 높은 유틸리티 함수 모음입니다. 
# dir(__builtins__)를 사용하면 전체 내장 함수 목록을 확인할 수 있습니다.
print(type("Hello"))  # type()도 대표적인 내장 함수
2. 표준 입출력 함수
출력 포맷을 지정하는 print(sep="구분자", end="끝문자")와 사용자 입력을 문자열로 받는 input() 함수입니다. 
# sep: 인자들 사이 구분자 지정, end: 줄바꿈 대신 출력 끝 문자 지정
print("010", "1234", "5678", sep="-", end=" [연락처]\n")
# 출력 결과 -> 010-1234-5678 [연락처]

# user_input = input("이름을 입력하세요: ") # 항상 문자열 str 타입으로 반환됨
3. 수치 및 집계 함수
리스트 등 시퀀스 데이터의 원소 총합을 구하는 sum(), 최대·최소값을 구하는 max(), min(), 반올림 round() 등입니다. 
numbers = [15, 42, 8, 99, 23]

print("합계:", sum(numbers))  # 187
print("최댓값:", max(numbers))  # 99
print("최솟값:", min(numbers))  # 8
print("반올림:", round(3.14159, 3)) # 3.142 (소수 셋째 자리까지)
4. 데이터 타입 변환 함수
프로그램 수행 도중 변수의 자료형을 다른 형태로 상호 전환할 때 쓰는 int(), float(), str(), list(), set() 등의 생성자 함수입니다. 
num = 100
str_num = str(num)       # 정수 -> 문자열 "100" 변환
list_char = list(str_num)  # 문자열 -> 문자 리스트 ['1', '0', '0']로 변환

print(list_char)
print(type(str_num))     #
5. 순회 및 정렬 함수
길이를 세는 len(), 원본 리스트를 건드리지 않고 정렬된 새 리스트를 반환하는 sorted(), 변수의 타입 일치 여부를 검사하는 isinstance()입니다. 
data = [5, 1, 3, 2, 4]

# sorted()는 리스트 메서드 sort()와 달리 원본을 유지하고 정렬본을 리턴
sorted_data = sorted(data, reverse=True)  # 내림차순 정렬

print("원본 유지:", data)         # [5, 1, 3, 2, 4]
print("정렬된 리스트:", sorted_data) # [5, 4, 3, 2, 1]
print("리스트 타입 확인:", isinstance(data, list)) # True
